# sln1 polynomials of knots

This repository provides the code for computing the Kashaev–Mangazeev polynomial $KM_n$ 
defined using the $2^n$-dimensional Nichols algebra defined as in [[KM]](https://arxiv.org/abs/2505.15569), 
which is conjectured to equal to the quantum knot polynomial associated with
the $2^n$-dimensional representation of the $sl(n|1)$ Lie superalgebra. 

See the top of the file ```sln1.py``` for detailed instructions.
